# Contributing to Bhasha Nirikhhon

Thank you for your interest in contributing to the Bhasha Nirikhhon artifact. This repository contains data and analysis code associated with an ICSE 2026 paper. Contributions are welcome, provided they follow the guidelines below to ensure clarity, reproducibility, and ease of review.

## Code of Conduct

All contributors are expected to be respectful and professional in all interactions related to this project.

## Scope of Contributions

Contributions may include:
- New analysis scripts corresponding to existing or extended research questions
- Additional data or derived datasets that follow the existing structure
- Improvements or fixes to existing scripts, data handling, or documentation

Contributions should remain aligned with the goals and methodology of the paper.

## How to Contribute

Please follow these steps when contributing:

1. Fork the repository and create a new branch named `feat/<short-desc>` or `fix/<short-desc>`.
2. Add new scripts, analyses, or datasets in appropriately named directories that follow the existing repository structure.
3. Keep changes focused and avoid unrelated refactoring.
4. Update `README.md` if the contribution affects data layout, execution steps, or usage instructions.
5. Open a pull request against the default branch with a clear description of the changes. When relevant, reference the affected research question or section of the paper.

## Branching and Commits

Use small, focused commits. Write commit messages in the imperative tense. Examples include:

- `Add script for RQ3 analysis`
- `Fix file path handling in RQ4 script`

## Quality and Reproducibility Guidelines

All scripts and analyses should be executable from the repository root directory. Use clear and consistent relative file paths. New scripts should rely only on data included in the repository or on external data sources that are explicitly documented. All inputs, outputs, and assumptions should be clearly described in code comments or documentation.

## Review Process

All contributions are reviewed by the repository maintainers. Review focuses on clarity, reproducibility, consistency with the existing artifact, and alignment with the paper’s methodology.
